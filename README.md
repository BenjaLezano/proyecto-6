# TrapZone - Proyecto 6

Sitio web dedicado a la difusión de la cultura del trap y reggaetón latino en Argentina y Chile.

## 🌐 Sitio Publicado en GitHub Pages
Puedes acceder al sitio en vivo a través del siguiente enlace:
[https://BenjaLezano.github.io/proyecto-6-trapzone/](https://BenjaLezano.github.io/proyecto-6-trapzone/)

## 🚀 Tecnologías utilizadas
* **HTML5**: Estructura semántica completa.
* **CSS3**: Estilos personalizados con variables y selectores específicos (sin exeso de `!important`).
* **Bootstrap 5.3.3**: Sistema de grillas responsive (`col-12`, `col-md-6`, `col-lg-4`) y componentes interactivos.
